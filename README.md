# promos

Launch videos for the projects I ship. Built with [brag](https://github.com/latent-spaces/brag) + Hyperframes, rendered locally, delivered per-project as GitHub Release assets.

## DevAtlas — 8-cut set (v1.0-devatlas)

[DevAtlas](https://devtomb.netlify.app/) — searchable index of 30,000+ developer tools,
APIs, datasets and OSS from GitHub awesome-lists, with daily trending leaderboards.

| Cut | Length | Format | Positioning |
|---|---|---|---|
| `devatlas-main.mp4` | 20s | 1920×1080 | The original brag — search → rank → fresh → logo |
| `devatlas-longer.mp4` | 25s | 1920×1080 | Long cut: + compare, + weekly-trends inbox |
| `devatlas-cinematic.mp4` | 22s | 1920×1080 | Trailer-scale: "Great tools hide in lists." |
| `devatlas-chaotic.mp4` | 16s | 1920×1080 | Hype reel: STOP DIGGING THROUGH AWESOME LISTS |
| `devatlas-detailed.mp4` | 25s | 1920×1080 | Feature-deep app-store pass (6 features) |
| `devatlas-reels.mp4` | 18s | 1080×1920 | Instagram Reels vertical |
| `devatlas-producthunt.mp4` | 20s | 1920×1080 | Product Hunt launch framing |
| `devatlas-twitter.mp4` | 15s | 1920×1080 | X/Twitter hook cut |

Every cut: music bed, UI SFX, real product copy extracted from the live site
(no invented claims), recreated product UI, `hyperframes check` clean before render,
poster frame baked as frame 0.

Per-cut share captions live in `devatlas/<cut>/share-copy.txt`.
The full creative plan: [`devatlas/BRAG_PLAN.md`](devatlas/BRAG_PLAN.md).
